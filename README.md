## About

I ship small, focused products around **short-form video workflows**: listing and downloading content, local editing with ffmpeg, and daily channel reports that land in Slack.

I care about installers that actually work on a clean Windows machine, clear READMEs, and automation that does not depend on a laptop staying on.
